# Undaunted (Dauntless 1.4.4 preservation fork)

A private-server backend for the Dauntless `1.4.4_shipping` (CL239827) client, forked
from [SyST3MDeV/Undaunted](https://github.com/SyST3MDeV/Undaunted).

- `UndauntedMetagame`: backend service (progression, store, bounties, escalation, social)
- `UndauntedDeployServer`: world server launcher and matchmaker
- `UndauntedInternalServer`: injected integration DLL
- `UndauntedLauncher`: launcher
