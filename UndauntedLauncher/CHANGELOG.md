# Undaunted Launcher 1.0.8 — 6 October 2026

- The launcher has been rewritten in Rust, with a much smaller installer.
- Existing Electron launchers can update directly to this release. Your saved login, game folder and language are retained where valid.
- Automatic signed updates remain available, including verification before installation.
- Fixed update installation for launcher folders containing spaces.
- Includes the updated game runtime DLL with the Undaunted private server credits.
- Removed the preview branding and enabled production updates.
